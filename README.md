# Barber Booking Bot

Serverless Telegram-бот для онлайн-записи к частному мастеру. Клиент выбирает свободное время и управляет записью самостоятельно, а мастер публикует расписание и получает уведомления в том же боте.

## Возможности

### Для клиента

- выбор свободной даты и точного времени;
- передача телефона через безопасную кнопку Telegram или запись без номера;
- просмотр, перенос и отмена будущих визитов;
- подтверждение записи и напоминания за 24 часа и за 2 часа.

### Для мастера

- защищённый кабинет с основной и резервной ролью администратора;
- публикация типовой смены, произвольного графика или отдельного окна;
- просмотр расписания и ближайших записей;
- ручная запись клиента без Telegram;
- завершение и отмена визита без удаления остальных слотов.

## Технические решения

- атомарное создание записи защищает один слот от двойного бронирования;
- дедупликация предотвращает повторную обработку одного Telegram update;
- webhook проверяется по секретному заголовку;
- роли администратора привязываются к конкретному Telegram-аккаунту;
- время хранится и преобразуется с явной поддержкой московского часового пояса;
- напоминания планируются через Durable Object Alarm.

```text
Telegram Bot API
       │ webhook
       ▼
Cloudflare Worker ─── booking workflow ─── Cloudflare D1
       │
       └── Durable Object Alarm ─── напоминания клиентам
```

## Технологии

- JavaScript, Node.js 20+
- Cloudflare Workers, D1 и Durable Objects
- Telegram Bot API
- SQL migrations
- встроенный тестовый раннер Node.js

## Локальный запуск

1. Установите зависимости: `pnpm install`.
2. Скопируйте `wrangler.example.jsonc` в `wrangler.jsonc` и заполните локальные параметры.
3. Скопируйте `.dev.vars.example` в `.dev.vars` и добавьте тестовые секреты.
4. Примените миграции: `pnpm db:local`.
5. Запустите проект: `pnpm dev`.

Проверки:

```bash
pnpm check
pnpm test
```

## Развёртывание

Создайте D1-базу, сохраните `BOT_TOKEN`, `WEBHOOK_SECRET`, `OWNER_CODE` и `BACKUP_OWNER_CODE` через Cloudflare Secrets, примените миграции и опубликуйте Worker. Для установки webhook передавайте `BOT_TOKEN`, `WORKER_URL` и `WEBHOOK_SECRET` только через переменные процесса. Необязательные `EXPECTED_BOT_USERNAME` и `BARBER_NAME` позволяют проверить аккаунт бота и настроить публичное описание.

## Результат и безопасность

Проект содержит 10 автоматических тестов для времени, расписания, команд, клавиатур и ручной записи. В публичной версии заменены рабочее имя бота, D1 ID и персональные названия; токены и коды доступа отсутствуют. Локальные секреты, состояние Wrangler и зависимости исключены через `.gitignore`.
